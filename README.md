# 星野 · Starlight Android

免费、无广告的中文观星 App；联网获取天气和国际空间站位置，星图按所设时间和地点生成。独立设计与实现，不隶属 iCandi Apps / Night Sky，不使用其代码、图标、品牌或美术素材。

**状态：0.3.7 开发预览版；尚未达到 Night Sky 全功能/性能等价。**

## 已实现

- 应用内检查 GitHub 新版本（包含预览版），启动后每天最多自动检查一次；由用户点击下载，校验 SHA-256、包名、版本代码和固定签名后交给 Android 系统安装。首次通过此来源安装需在系统设置允许，并由用户确认；无静默安装。
- 观测计划页可按需获取 Open-Meteo 云量、降水概率、模型能见度与气温预报，显示获取时间和坐标；连接偶发失败时尝试一次重连。成功预报可在同一位置缓存三小时：请求失败时标明显示的是上次预报，过期或换位置不使用缓存。只有点击联网天气时，所设经纬度才会发送到 Open-Meteo。中国境内位置可查询，但国内各网络对境外接口的连通性尚未实测，不能保证每次可用。
- 观测计划把近三小时内获取的同位置天气预报与太阳高度结合，标出未来夜间采样时段的模型条件，并可一键跳到该时刻星图；不联网时照常显示离线天体计划。自选历史/未来时刻不会错误套用现实天气。条件阈值是观星提示，不代表现场天空或天气预警。
- 搜索和观测计划中新增 ISS 实时位置入口：按需请求 Where the ISS at? 的带时间戳位置，用所设位置在本机换算方位、仰角和距离。位置页面打开时约每 8 秒刷新，星图标记只保留约 12 秒。无有效新数据时移除标记；没有预测过境、星站光照或肉眼可见性保证。联网请求不发送所设经纬度，但第三方服务可见网络连接信息。中国大陆网络的连通性尚未真机验证。

- 根据太阳高度呈现夜晚、暮光、白天渐变，白天自动压低恒星和梅西耶目标显示强度；恒星颜色按星表色指数分档，亮星使用可复用光晕。原创银河淡雾依照银河坐标排列。赤道网格、时角刻度和 10°/20°/30° 视场圆环可开关；选中星座可高亮其连线。画面只作视觉提示，不预测云量、天气或当地光污染。
- 月亮在星图中按当前计算出的照明比例绘制月相圆盘，亮面朝向太阳在屏幕上的投影方向；仍为示意图，不呈现月面纹理或真实角直径。

- 支持系统自动旋转时横屏和竖屏观星；旋转后保留当前目标和时间，相机 AR 预览重新测量视场。低屏高横屏采用紧凑控件布局。地平线下的星座线不再绘制。

- 屏幕方向指引：手机倾斜时使用真实画面投影判断目标位于上、下、左、右；目标超出画面时显示边缘箭头，身后及地平线下目标分别提示。
- 星图按星等预先排序，只投影当前显示阈值内的恒星；默认阈值 ≤5.2 等时约处理 2,072 颗候选星，高倍缩放仍可显示完整至 7 等的 15,598 颗恒星，选中较暗恒星依然可见。

- 110 个梅西耶深空天体：星云、星团、星系等，可搜索 M31 / NGC224 / 中文名，查看地平坐标并在星图定位。较亮目标以青色菱形标记；目录总星等不等同于肉眼可见性。

- 首次打开引导设置观测位置：可选择本机定位或手动经纬度。大致位置权限可用；拒绝时明确提示示例天空，手动坐标不会被后续位置更新覆盖。

- 未来 24 小时离线天体观测计划：暗夜时段、月面照明比例、月亮与行星观测窗口，点击推荐时刻进入星图。按 10 分钟采样，时间采用手机本地时区；联网天气需另行点击。

- 实验性相机 AR：后置摄像头预览与方向传感器星图叠加，按需申请权限，不拍照、不录音、不上传；退出和后台释放相机。
- 安卓打开后自动进入指向模式。直接用屏幕姿态矩阵驱动星图，自动修正磁偏角，无需指定东南西北；不再应用旧版手动方向偏移。AR 仍可调整相机视场。
- 月相日历：查询未来 8 次主要月相，支持指定日期和定位当时的月亮。
- 观测笔记 JSON 导出和导入：系统文件选择器，不请求全盘存储权限；导入保留本机同名记录。
- 15,598 颗视星等 ≤7 的真实恒星，HYG v4.1 数据；根据地点、时间计算地平坐标并考虑岁差。
- Astronomy Engine 离线计算太阳、月亮、水星、金星、火星、木星、土星、天王星、海王星与冥王星；显示视星等、距离、高度角、方位角、升落时间和月面照明比例。
- Android 原生旋转向量传感器接入，手机背面指向天空，磁偏角修正、平滑朝向、缺传感器时手动模式、离开前台停止传感器和计时。
- 拖动、双指缩放、点击天体、名称/HIP 搜索、目标方向引导。
- 88 个星座支持中英文名称、缩写搜索与参考中心定位；其中 86 个有星座连线，另有北斗七星星群连线。连线是视觉约定，非官方星座边界。
- 定位权限按需申请，可拒绝并填写经纬度；默认北京位置明确标为示例。
- 时间前后移动、自定义日期、红色夜间模式、观测收藏和本地笔记。
- 无账户、无订阅、无广告。观星计算、笔记和位置设置在本机；启动更新检查访问 GitHub，只有主动查看天气时才将所设经纬度发给 Open-Meteo。

## 与目标产品的差距

| 项目 | 当前状态 |
| --- | --- |
| 相机 AR | 已实现实验性叠加，需真机校准与兼容性验证；平面识别和行星模型未实现 |
| 卫星 / ISS 实时轨道 | ISS 当前联网位置快照已实现；其他卫星、轨道预测和过境提醒尚未实现 |
| 十亿级恒星云数据库 | 未实现；当前离线星表 15,598 颗 |
| AI 问答、语音导览、空间音频 | 未实现；没有伪装成 AI 的固定回答 |
| 星座连线/插画与深空天体 | 86 个星座有连线，2 个只有参考中心；110 个梅西耶天体，其他深空目录与星座插画仍未实现 |
| 天气、光污染图、观星条件与提醒 | 已接入按需查询的天气模型预报；光污染图与提醒未实现 |
| 多人同步、社交分享、观测照片 | 未实现 |
| 原版性能等价 | 未验证，需不同档位 Android 真机基准 |

这些差距不能仅靠换皮消除。目标是后续已实现功能保持免费，但本项目没有为云服务作出无限资源承诺。

## 使用

Android 8.0+，安装预览 APK。第一次打开先设置实际位置，App 自动开启手机指向；首次打开可选择允许定位以自动匹配当地天空，或手动设置经纬度。右侧准星可切换手动模式。画面中心对应手机背面方向。AR 不会识别相机照片中的星星，其叠加位置来自星表和传感器。附近磁铁和磁性手机壳会影响方向；可将手机转动呈 8 字校准。右侧齿轮显示传感器精度状态；不需要手动指定方向。缺少旋转向量传感器时仍可手动探索。

太阳显示仅用于位置参考，不能作为安全直视太阳的依据。地平线下天体会变暗，它们在实际天空不可见。

本地笔记在卸载/清除数据后会丢失。0.2.0 可在「观测收藏」导出 JSON 备份，再在新版导入；同名记录保留本机版本。0.1.0 没有导出功能，请在卸载前手动复制重要笔记。

0.2.2 是固定发布签名的基线版。由于 0.1.0～0.2.1 使用过临时开发签名，首次切换到 0.2.2 时可能需要导出记录、卸载旧版再安装；从 0.2.2 开始，后续由官方工作流发布且版本号更高的 APK 可以直接覆盖升级。恒星未应用自行、大气折射；不适合科学测量。

## 构建

Java 17、Gradle 8.9、Android SDK Platform 35、Build Tools 35。

```sh
gradle :app:assembleDebug
npm install
npm test
```

不依赖第三方 Android UI 库。也可用 Android Studio 打开根目录并使用 Gradle 8.9。仓库未包含 Gradle wrapper 二进制，可用 `gradle wrapper --gradle-version 8.9` 生成。

GitHub Actions 在 main 提交时提供 APK artifact；首次构建成功时自动创建预览 Release。发布构建使用仓库 Secrets 中的固定私钥，私钥不会提交到源码。签名证书 SHA-256：`3EA20712AB847EE5E2247CD5D4673BFA5A5467071A654E5E6066DA42A4867558`。

## 架构与测试

原生 Java Activity 提供传感器和定位桥接，本地 WebView Canvas 绘制星图。仅加载内置 https 本地映射资源；拦截其他请求与跳转。星图水平向量每 30 秒重算，交互重绘最多约 30 FPS，DPR 上限 2，按星等/视场裁剪。

自动测试覆盖屏幕倾斜时的找星引导、边缘箭头计算、暗星选中、投影方向、背面剔除、方位角环绕、48 个不同位置/日期/天体的两条坐标转换路径，以及春分太阳高度的物理合理性。DOM 逻辑测试已覆盖搜索、笔记保存、经纬度校验、时间、夜间模式、列表和传感器缺失回退；Canvas 用桩替代，不代表实际视觉渲染通过。构建和 APK 签名已在 Linux 验证。

**未完成：相机预览与标记对齐真机验收、相机占用/权限回退测试、真机启动、WebView 视觉验收、传感器朝向校准、权限完整矩阵、不同系统版本适配、FPS/耗电/内存基准。** 因此不声称已达到商用品质或与 Night Sky 同等性能。

### v0.3.6 性能改进

恒星按天球分区建立索引，移动视角时剔除屏幕外分区；保留原有绘制优先级。点击天体使用屏幕网格索引。索引随天文坐标更新重建，不随手机转动重建。120 组投影测试没有遗漏可见星点，1,000 次点击与全量扫描一致；模拟目录候选数量平均减少 77.4%，不是手机帧率提升比例。尚未进行真机帧率、内存和功耗测试。

### v0.3.7 方向显示稳定性

对系统方向数据增加自适应四元数平滑，降低小幅抖动，转动时加快响应；首次读取、恢复及大幅姿态变化直接更新。此功能不是新的传感器融合，也不能修正磁场干扰。模拟轨迹验证通过，真机 AR 对齐、延迟和功耗仍需测量。
